## 🛠️ Repository Structure
This repository is organized by course modules. Each folder contains high-fidelity HTML notes with code snippets and key takeaways from the bootcamp sessions.

- `/typescript`: Modern TypeScript features and best practices.
- `/express`: Server-side development with Node.js.
- `/sql`: Relational database management and querying.
- `/oop`: Object-Oriented Programming concepts in JS/TS.
- `/nestjs`: Enterprise-grade backend architecture.
- `/devops`: Modern deployment and containerization workflows.
- `/nextjs`: Advanced React patterns and fullstack development.
- `/realtime`: Bidirectional communication.
- `/ai`: AI model integration and prompt engineering.
