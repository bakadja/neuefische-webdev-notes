TypeScript Basics

📝 Mes Notes

Types Primitifs

  • string — chaînes de caractères
  • number — nombres (entiers et décimaux)
  • boolean — true ou false
  • null et undefined

Déclaration de Variables

let name: string = "Kevin";
const age: number = 25;
let isStudent: boolean = true;

Fonctions

function greet(name: string): string {
    return `Hello, ${name}!`;
}

Interfaces

interface User {
    name: string;
    age: number;
    email?: string; // propriété optionnelle
}
💡 Rappel : TypeScript est un sur-ensemble de JavaScript qui ajoute le typage statique.
