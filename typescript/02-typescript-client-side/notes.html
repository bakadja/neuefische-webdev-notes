Node.js vs Navigateur

Cette section explique la différence fondamentale entre les environnements d'exécution. Vous y découvrirez pourquoi TypeScript a besoin d'être configuré spécifiquement pour comprendre les objets du navigateur web, et comment la compilation permet de transformer notre code typé en JavaScript lisible par les navigateurs.

🖥️ Le Problème Node.js

Node.js n'a pas de DOM. Si vous exécutez document.getElementById() directement dans Node, l'application plantera avec une ReferenceError.

> node main.js
ReferenceError: document is not defined

⚙️ La Solution tsconfig.json

Pour développer côté client, nous devons indiquer au compilateur TypeScript d'inclure les définitions de l'API du navigateur via l'option lib.

{
  "compilerOptions": {
    "target": "ESNext",
    "lib": ["dom", "esnext"],
    "module": "ESNext"
  }
}

DOM & Assertions de Type

Explorez ici comment TypeScript gère les éléments HTML. Puisque TypeScript ne peut pas deviner quel type d'élément se cache derrière un ID, il renvoie un type générique. Cette section vous permet de découvrir les différentes assertions (`as`) nécessaires pour débloquer les propriétés spécifiques de chaque élément HTML.

Le Concept : document.getElementById() retourne HTMLElement | null. Nous utilisons l'opérateur as pour préciser l'identité réelle.

Fetch API & Interfaces

Découvrez ici comment consommer des données externes (comme l'API Open Library DBooks). Puisque les données récupérées sur le réseau sont de type inconnu (`any`), vous verrez comment définir des contrats stricts (Interfaces) pour garantir la structure des données avant de les utiliser dans votre application.

1. Définir le contrat (Interfaces)

interface Book {
  id: string;
  title: string;
  authors: string;
}

interface SearchResult {
  status: string;
  books: Book[];
}

2. Asserter la réponse réseau

async function fetchBooks(query: string): Promise<Book[]> {
  const response = await fetch(`.../${query}`);
  
  // Sans 'as', data serait de type 'any'
  const data = (await response.json()) as SearchResult;
  
  return data.books; 
}
